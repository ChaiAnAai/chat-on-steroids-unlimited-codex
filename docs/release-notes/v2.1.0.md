# 知行 · Chat On Steroids 2.1.0

## 2.1.0

这是基于上游 v2.0.9 的源码里程碑版本，集中保存桌面重设计、同会话工作流、账号隔离基础、MCP 中文浏览和本地 Skills 的升级实现。应用与配套扩展版本均为 **2.1.0**，桥接协议为 **14**。此标签不表示所有真实服务与安装验收已经完成。

## 本次包含

- 中性深色、浅色和系统主题，强调色、字号及密度设置；调整导航、输入区、管理页和窄窗口排版。
- 独立发送与停止入口、任务状态摘要、持久操作反馈、计划历史和同会话 checkpoint 续行基础。
- 账号记录、专用或已有浏览器 Profile 选择、独立配对及部分账号作用域保护。复用已有 Profile 不复制 Cookie。
- 基于官方 Registry 的 MCP 搜索、中文用途说明、图标与配置提示，以及收藏、最近使用和已加载结果筛选。
- 内置三个 Skills 和本地文件夹导入、版本保留、项目启用与技能详情界面；技能资料不替代工具权限。
- 基于 PhotoSwipe 的图片查看界面、首次引导、可选 CLIProxyAPI 连接管理和测试构建身份清单。
- 保留第三方代码与中文目录资料的许可证、来源和原始产品身份。

## 使用与兼容

- 默认在项目主对话中规划、执行及分段续行；自动化开关不代表任务正在运行。
- 同会话续行受检查点、目标版本、送达状态、额度信息和每段最多十次续行预算约束。
- 协议 13 扩展不能领取协议 14 任务；需要使用本标签中的配套扩展。
- 更新检查与扩展下载指向本分支所属仓库。对应安装包和扩展资产尚未发布时，不能把源码标签当作可下载的安装程序。
- 保留应用标识与数据目录。开发或测试请使用独立数据目录；本次发布不执行正式安装、数据迁移或历史自动任务恢复。
- `scripts/package-accounts-preview.cjs` 中旧预览编号用于历史测试流程，不作为 2.1.0 安装包发布入口。本地 `preview-build.json` 和测试包不进入 Git。

本次源码推送不替换正在使用的程序。开发者可在另一工作树检出原标签并使用独立测试数据；不要用旧版程序直接覆盖升级后的唯一数据副本。正式升级前需先备份应用配置、会话、产物及浏览器绑定记录，并完成迁移演练。
