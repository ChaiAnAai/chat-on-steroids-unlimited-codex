# 2.1 连接设置与扩展安装收敛

本次修复将 Plugins 连接配置并入“设置 → 连接与扩展”，并为浏览器扩展提供由主进程管理的安装路径。独立预览包为 `2.1.0-accounts-preview.9`，配套扩展 `2.1.0`，协议 `14`。

## 已实现

- 设置导航按“通用 / 连接与能力 / 运行与诊断”分组；语言归入外观，版本信息移到连接页底部；连接页直接打开账号管理。
- 自动化搜索明确只搜索当前页，避免误以为能搜索整个设置。
- 同一表单维护 Core、Desktop、Plugins 隧道与共用密钥，不再从插件页打开另一套连接设置弹窗。
- 插件页保留设置导航；配置入口按连接方式定位到隧道字段或 ChatGPT 连接器地址信息。
- 连接页提供隧道、密钥、浏览器扩展、ChatGPT 连接器信息快捷入口；Plugins 连接器名称、说明、地址和状态不再从通用设置中排除。
- 插件隧道沿用现有保存队列、保存反馈和草稿保护。
- 扩展安装区展示只读路径，并提供复制路径、打开相同目录和准备／修复操作。主进程重新解析路径，忽略调用方提供的路径。
- 安装版从包内扩展恢复到稳定的 `userData/extension`，不依赖 GitHub 下载，也不需要用户选择 ZIP 的保存位置。目录内容损坏时重新准备；修复失败不显示成功。
- ZIP 导出收进“更多扩展操作”，只作为备份。完整包和稳定副本都缺失时明确报错，不下载任意版本。
- 明确区分文件就绪、浏览器加载、账号确认，打开目录或复制路径不代表已安装、已登录。
- 打包只收录编译后的 main、preload、renderer；本地诊断日志、截图及其他 out 产物不进入应用包。

## 安装路径怎么用

1. 打开“设置 → 连接与扩展 → 安装浏览器扩展”。
2. 等待文件夹就绪，点击“复制安装路径”。
3. 在目标账号的 Chrome／Edge Profile 中打开 `chrome://extensions`／`edge://extensions`，开启开发者模式。
4. 点击“加载已解压的扩展程序”，在文件夹选择窗口中粘贴路径并选定目录。
5. 返回知行完成账号连接确认。已加载的目录不要移动或删除；更新后在浏览器扩展页重新加载。
