## 动效与操作反馈补充

- 菜单采用 180ms、4px 的淡入位移，顶部菜单与输入工具菜单使用对应方向；右侧详情采用 8px 淡入，不重放消息时间线。
- 原生语言、外观和重命名弹窗增加可反向的开合过渡，保留原生模态和焦点语义。
- 侧栏宽度变化平滑过渡，指针拖动期间禁用过渡，并突出分隔线。
- 任务操作按钮预留位置，悬停不再改变标题截断；触屏保持入口可见，键盘焦点离开菜单时收起。
- 输入框和搜索增加聚焦反馈，按钮增加轻微按下位移，控件统一键盘焦点轮廓。
- 应用内及系统的减少动画设置覆盖上述效果；实际 Electron 检查包含快速重复打开弹窗和两种设置。

验证脚本在独立临时配置中运行，不代表已重启用户当前正在使用的窗口。

### 视觉与连续动效复核

后续将表面过渡统一为 240ms。菜单使用原生 `::details-content` 在开合两端过渡，展开时立即允许内容获得焦点，避免可见性过渡阻断键盘。引导内容使用自动高度过渡，详情栏使用网格宽度与出入过渡；收起的侧栏和详情栏立即设为 inert，退出动效期间不接收操作。

外观控件统一为紧凑色块、开关、细滑轨；欢迎区标题、快捷入口、输入区与表面阴影统一层级。模型滑块采用细轨道和 44px 操作区域，保持真实模型校验。

实际 Electron 测试断言菜单展开和收起各有 0 到 1 之间的透明度中间帧，并可通过 `COS_RECORD_MOTION=1` 记录 `workspace-motion.gif`。动图来自临时配置的真实窗口。用户反馈时运行路径仍为 `release/ui-workspace`，新版快捷方式不会替换仍在托盘运行的旧进程，需明确提示完整退出后重新启动。

## 降低首次配置难度

连接方式移至引导顶部。用户选择 Cloudflare 快速连接时，沿用现有连接实现并隐藏不适用的 Tunnel ID/API key 两步；明确提示临时公开地址及重启地址变化，不自动切换既有配置或发起连接。第三方登录、创建连接器与扩展授权仍需用户操作。

引导默认只展开当前步骤，完成情况来自原有连接证据；标题可展开复查，显示全部可恢复完整说明。正在编辑的输入和未验证的可选连接器不会被后台进度隐藏。进度分母只包含适用步骤。

模型选择保留观察到的模型与档位及发送校验，增加模型快捷分段、两端说明、更大的拖动命中区和跟随强调色的刻度。检查了 MIT 的 [noUiSlider](https://github.com/leongersen/noUiSlider) 和 [OverlayScrollbars](https://github.com/KingSora/OverlayScrollbars)；本轮需求用原生 range 和现有滚动区域即可满足，未引入或复制第三方代码。

实际 Electron 引导检查使用临时配置；模型滑块另在隔离 iframe 中运行真实渲染模块与测试目录，检查键盘和分段按钮。`workspace-model-slider-fixture.png` 是组件测试截图，不能作为账户模型可用性的证据。

## 窗口与面板比例

外观弹窗最大宽度调整至 700 CSS px，标题和底部操作留在固定网格行，中间内容独立滚动；语言弹窗同样固定底部操作。重命名弹窗明确居中并限制高度。

主内容区域使用容器查询：剩余宽度至少 880px 时，详情栏以 320px 并排显示；否则采用覆盖面板，避免受侧栏宽度影响而把聊天区压窄。内容宽度不超过 600px 时，输入区菜单贴合输入框宽度并限制高度。窄窗口侧栏与输入区留白也相应缩小。

实际 Electron 在 1600×1000、1280×800、1000×700、800×600、640×480 的内容区尺寸下检查弹窗边界、操作按钮、详情栏聊天宽度及输入菜单。测量结果保存在 `release/ui-evidence/responsive-layout-checks.json`；这些是渲染视口检查，不等同于在五台不同 DPI 显示器上人工操作。
